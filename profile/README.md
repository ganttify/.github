# Ganttify

Ganttify turns Basecamp, Todoist and Trello projects into interactive Gantt charts and syncs date changes back to where the work lives. Gantt charts for GitHub issues and for Google Calendar are in invite-only beta.

- Gantt charts for GitHub: [gantt-chart.com/github](https://gantt-chart.com/github?utm_source=github&utm_medium=org_profile)
